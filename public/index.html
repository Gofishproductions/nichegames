How Scan works

Existing Firebase games appear immediately. Social filters use cached public game/creator links, including Discord when Roblox exposes one. Choosing a Genre switches to genre-only mode and scans that category broadly. Use All games to bypass every filter and show the entire stored catalog.

Coverage

Roblox no longer provides one exhaustive public endpoint for every experience. Nichegames grows coverage over time using Explore, paginated Search, recommendation expansion, and every universe ID it has found before. There is no display-result cap; pagination only changes what is visible on one page.

Known

Unresolved

The ID still needs to be converted or fetched from Roblox. The hourly catalog builder keeps working through this backlog.
